Dashboard CTD

Sistema interactivo de visualización de perfiles oceanográficos para diferentes ambientes marinos. Explora temperatura, salinidad y oxígeno en tiempo real.

🚀 Cómo usar el Dashboard CTD

1

Requisitos del Sistema

Asegúrate de tener instalado Python 3.8 o superior en tu sistema.

python --version # Debe mostrar Python 3.8 o superior
2

Descargar el Código

Clona o descarga el repositorio de OLITAI desde GitHub.

git clone https://github.com/gogoland1/olitai.github.io.git cd olitai.github.io
3

Instalar Dependencias

Ejecuta el script de instalación automática o instala manualmente.

# Opción 1: Instalación automática python install_dependencies.py # Opción 2: Instalación manual pip install -r requirements_web.txt
4

Ejecutar el Dashboard

Lanza el dashboard con el script de ejecución automática.

python run_dashboard.py

El navegador se abrirá automáticamente en: http://localhost:5000

🌊 Ambientes Marinos Disponibles

Fiordo Patagónico (0-100m)

Aguas frías estratificadas con fuerte haloclina. Características de fiordos con influencia de agua dulce glacial.

  • Temperatura: 4-12°C
  • Salinidad: 5-35 PSU
  • Oxígeno: Alto en superficie, disminución gradual

Delta de Río (0-50m)

Gradiente salino pronunciado con alta variabilidad debido a flujos fluviales estacionales.

  • Temperatura: 8-22°C
  • Salinidad: 0.5-25 PSU
  • Oxígeno: Variable, influenciado por aportes terrestres

Ambiente Costero (0-500m)

Zona de transición tierra-mar con termoclina estacional y eventos de surgencia.

  • Temperatura: 10-25°C
  • Salinidad: 33-36 PSU
  • Oxígeno: Máximo subsuperficial por surgencias

Océano Abierto (0-2000m)

Estructura vertical compleja con múltiples masas de agua diferenciadas por temperatura y salinidad.

  • Temperatura: 2-28°C
  • Salinidad: 34-37 PSU
  • Oxígeno: Zona de mínimo intermedio

✨ Características del Dashboard

Controles Modulares

Sliders para mezclar ambientes en tiempo real y ajustar profundidad máxima.

Visualización Interactiva

Gráficos dinámicos con Plotly para perfiles de T, S y O₂.

Diagramas T-S

Análisis de masas de agua con diagramas temperatura-salinidad.

Estadísticas

Métricas oceanográficas calculadas en tiempo real.

Exportación

Descarga de datos y gráficos en múltiples formatos.

Responsive

Diseño adaptable para dispositivos móviles y tablets.
